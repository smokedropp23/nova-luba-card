# Nova UI – Luba Card

A dynamic and visually rich Home Assistant card for Mammotion robotic mowers.

---

## Features

- Dynamic status-based interface
- Desktop & Mobile layouts
- Automatic state switching
- Multiple Mammotion models
- Beautiful Nova UI design
- HACS compatible

---

## Supported Models

- Luba 1
- Luba 2
- Luba 3
- Luba Mini 1
- Luba Mini 2
